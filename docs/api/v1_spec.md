# REST API v1 Specification

Base URL: `/api/v1/`

## Key Endpoints
- `GET /api/v1/schools/`: List authorized school profile.
- `GET /api/v1/students/`: List tenant-scoped student profiles.
- `GET /api/v1/attendance/`: Query attendance records.
- `GET /api/v1/marks/`: Query published student marks.
- `GET /api/v1/invoices/`: View student fee invoices.
